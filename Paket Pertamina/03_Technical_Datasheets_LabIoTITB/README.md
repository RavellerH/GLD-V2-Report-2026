# 03 — Technical Datasheets (Lab IoT ITB)

10 file PDF, datasheet teknis resmi Revisi 4.0 yang diterbitkan **Lab IoT ITB**, tersedia dalam Bahasa Indonesia (`-ID`) dan Inggris (`-EN`) untuk 5 cakupan:

| File | Cakupan |
|---|---|
| `Technical-Datasheet-Whole-System-*` | Arsitektur end-to-end GasleakDetector → CH → Gateway → broker → Server: alur operasional, routing/RF, jaringan & keamanan (TLS/AES-GCM), daya, komisioning, batas kapasitas & keamanan sistem |
| `Technical-Datasheet-GasleakDetector-*` | Spesifikasi perangkat sensor GLD |
| `Technical-Datasheet-CH-*` | Spesifikasi Cluster Head |
| `Technical-Datasheet-Gateway-*` | Spesifikasi Gateway |
| `Technical-Datasheet-Server-*` | Spesifikasi aplikasi Server |

## Catatan
- Dokumen ini adalah **sumber asli dari Lab IoT ITB** (bukan hasil olahan LGU/Claude) — dipindahkan apa adanya dari `Sumber Dokumen/Technical-Datasheets-Lab-IoT-ITB/` untuk melengkapi paket dengan spesifikasi teknis level perangkat yang lebih detail dari `Datasheet_Sistem_GLD_Arsitektur_ServerJaringan.html` di folder `01_Pilot_Field_Testing/`.
- Sudah dikonfirmasi sinkron dengan Datasheet Sistem konsolidasi LGU (per 4 September 2026).
- `Technical-Datasheet-GasleakDetector-*.pdf` berukuran lebih besar (~8 MB) karena memuat diagram/foto perangkat.
