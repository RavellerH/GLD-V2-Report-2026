## Cara pakai

- File `.pdf` — paling praktis untuk dibagikan/dibaca cepat di HP (mis. via WhatsApp), termasuk lampiran foto/CAD.
- File `.html` — buka di browser (Chrome/Edge/Firefox), tidak perlu internet, menampilkan elemen interaktif yang tidak muncul di PDF (mis. **viewer 3D** untuk desain bracket di `Pembagian_Persiapan_Instalasi_RU-IV_Cilacap.html`). Bar navigasi di bagian atas tiap file sudah disesuaikan agar hanya menaut ke keenam dokumen dalam folder ini (bukan bar navigasi penuh ~14 dokumen dari repo utama) — semua tautan di bar tersebut berfungsi normal. Beberapa tautan di **isi/footer** dokumen (mis. "Dokumen acuan lebih rinci") masih menyebut dokumen lain yang tidak ada di folder ini (Knowledge Graph, Checklist Instalasi, Datasheet Sistem, dst.) — itu murni rujukan sumber, hanya berfungsi bila dibuka dari folder `Deliverables/` pada repo utama.
