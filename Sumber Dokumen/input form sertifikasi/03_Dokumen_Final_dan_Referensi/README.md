## Catatan penting

Kedua file referensi adalah dokumen publik milik manufaktur pihak ketiga (FFE Ltd. dan Honeywell Analytics) untuk produk mereka sendiri — **bukan data produk GLD**. Angka-angka di dalamnya (dimensi, gap, torsi, dsb.) hanya dipakai sebagai gambaran format dan orde-besaran tipikal yang lazim diminta ExCB untuk produk Ex d IIC sejenis, sebagaimana dijelaskan di setiap sitasi pada dokumen FINAL. Nilai aktual untuk GLD V2 tetap wajib diukur/dihitung/disertifikasi sendiri melalui vendor casing dan laboratorium uji — lihat Lampiran B (RFI) pada dokumen FINAL.
