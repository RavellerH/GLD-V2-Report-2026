# Checklist Persiapan Sertifikasi IECEx / ATEX — GLD V2 2026

Sumber: `IECEx ATEX Certification Information Requirements_Ind.docx`

## 1. Dokumentasi Teknis

### 1.1 Deskripsi Produk
- [ ] Nama produk, model, dan daftar spesifikasi
- [ ] Deskripsi fungsi + parameter teknis lengkap (kelistrikan, mekanik, dll)
- [ ] Foto produk jelas: keseluruhan + komponen utama
- [ ] Tujuan penggunaan & lingkungan pemasangan:
  - [ ] Kelompok gas IIC / IIB / IIA (jika berlaku)
  - [ ] Kelas temperatur T1–T6
  - [ ] Rentang temperatur lingkungan
  - [ ] Klasifikasi area Zona 0/1/2 atau Zona 20/21/22

### 1.2 Gambar Teknik (lengkap, dengan dimensi, toleransi, material)
- [ ] Gambar perakitan (assembly drawing)
- [ ] Gambar komponen
- [ ] Diagram skematik kelistrikan
- [ ] Layout PCB (jika berlaku)
- [ ] Struktur enclosure/casing + parameter proteksi ledakan (celah/gap, panjang, volume)
- [ ] Gambar junction box
- [ ] Gambar terminal
- [ ] Gambar sambungan pentanahan (grounding)

### 1.3 Bill of Materials (komponen utama yang memengaruhi proteksi ledakan)
Komponen wajib dicantumkan:
- [ ] Enclosure/casing
- [ ] Gasket/seal
- [ ] Terminal
- [ ] Cable entry device
- [ ] Sakelar
- [ ] Sumber cahaya
- [ ] Baterai
- [ ] Bahan potting
- [ ] Komponen plastik
- [ ] PCB

Per setiap komponen cantumkan:
- [ ] Produsen
- [ ] Model dan spesifikasi
- [ ] Jenis/grade material (mis. sesuai IEC 60079-0 Appendix A)
- [ ] Sertifikasi yang sudah dimiliki (UL, ATEX, CCC, dll)
- [ ] Parameter teknis: CTI, flame retardancy, ketahanan kimia, Tg

### 1.4 Lembar Spesifikasi / Data Sheet Material Non-Logam
- [ ] Ketahanan temperatur tinggi & rendah
- [ ] Ketahanan penuaan (anti-aging)
- [ ] Sifat antistatik
- [ ] Ketahanan api
- [ ] Nilai CTI
- [ ] Ketahanan kimia
- [ ] Laporan pengujian / deklarasi kesesuaian dari pemasok

### 1.5 Proses Manufaktur
- [ ] Pengendalian ketelitian pembuatan enclosure
- [ ] Perlakuan permukaan tahan ledakan
- [ ] Proses pengelasan
- [ ] Proses potting
- [ ] Proses die casting
- [ ] Proses bonding/perekat

### 1.6 Perhitungan
- [ ] Perhitungan & penjelasan proteksi ledakan (jika berlaku)
- [ ] Perhitungan kelompok/kelas temperatur (estimasi titik terpanas produk)

### 1.7 Draft Manual
- [ ] Petunjuk penggunaan & instalasi (draft):
  - [ ] Peringatan keselamatan
  - [ ] Metode pemasukan kabel
  - [ ] Torsi pengencangan
  - [ ] Persyaratan grounding
  - [ ] Persyaratan pembersihan
  - [ ] Petunjuk pengoperasian
  - [ ] Pemeliharaan: frekuensi, kegiatan, tindakan pencegahan

### 1.8 Label & Sertifikat Komponen
- [ ] Informasi nameplate/label produk (seluruh marking wajib ATEX)
- [ ] Sertifikat ATEX Ex Components untuk semua komponen yang bersertifikat Ex

## 2. Informasi Sampel
- [ ] Model sampel
- [ ] Nomor seri
- [ ] Kondisi/status sampel (bisa dinyalakan & dioperasikan?)
- [ ] Fixture pengujian / peralatan bantu untuk pengujian
