2 Overview and architecture
2.1 Product overview
GasleakDetector combines multi-channel sensing, local processing, a physical alarm output, and two communication interfaces in
one field endpoint.

    Architecture                8 analog channels                                      Control                    ESP32-S3

    Primary link                LoRa STAR to CH                                        Local link                 RS-485 Modbus

●        Acquires eight sensor channels with per-channel power control.
●        Runs local processing in Running/Inference mode.
●        Sends telemetry and alarm events to CH over LoRa STAR.
●        Provides a steady 24 V output for an external alarm device.

8.3 Alarm-output logic
The 24 V alarm output provides AUTO mode for normal operation and MANUAL mode for controlled testing.

 Mode                      Control condition                                                                     24 V alarm output

 AUTO                      Inference asserts alarm                                                               Active

 AUTO                      Inference does not assert alarm; clear-state persistence succeeds                     Inactive

 AUTO fail-safe            Clear-state persistence fails                                                         Remains active until a valid clear can be
                                                                                                                 persisted

 MANUAL                    Test command ON                                                                       Active

 MANUAL                    Test command OFF                                                                      Inactive

 Note: MANUAL mode is not stored as a permanent operating mode. After a device restart, the initial mode is AUTO. Failure to persist the clear
 state retains the alarm ON as a fail-safe. When the 24 V output is active, the one-second ON/one-second OFF audible and visual pattern is
 generated by the powered alarm device.


8.4 Modbus status word
Register 0 condenses subsystem readiness, inference validity, alarm state, and power source into one 16-bit status word.

 Register 0 bit                                Meaning when set

 0                                             ADS1256 ready

 1                                             DAC ready

 2                                             LoRa ready

 3                                             ML runtime ready

 4                                             Inference result valid

 5                                             Alarm active

 6                                             ST_P source = 24 V

 7                                             External power detected

 Protocol behavior                                Condition

 Value format                                     All register values are unsigned 16-bit; the most significant byte is sent first.

 Read quantity                                    1-8 consecutive registers from a valid start address.

 Write functions                                  Not supported; Modbus exception response 01 (illegal function).

 Invalid address                                  Modbus exception response 02 (illegal data address).

 Invalid quantity                                 Modbus exception response 03 (illegal data value).


8.5 Modbus reading guide
Use the following steps to connect a PLC, HMI, SCADA, or master application to GasleakDetector without writing device
configuration.

 Step               Instruction

 1                  Set the master RS-485 port to 9600 bit/s, 8N1, no parity; use Unit ID 1.

 2                  Select FC03 or FC04, then send a start address 0-7 and quantity 1-8 that stays entirely within that range.

 3                  Read each word as unsigned 16-bit big-endian. Register 3 is in mV; register 2 is in percent.

 4                  Check the RTU CRC and any exception response before using values in the supervisory application.
